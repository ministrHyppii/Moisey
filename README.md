# 🛡️ Бот-модератор для Discord

Учёт игроков для нескольких серверов: карточки (как на скриншоте), предупреждения, выговоры, ЧС, таблицы ролей.
Каждый сервер настраивается отдельно. Токен хранится в `.env`.

## Запуск

1. Python **3.10+**. Установка: `pip install -r requirements.txt`
2. [Developer Portal](https://discord.com/developers/applications) → ваше приложение → **Bot**:
   включите **Server Members Intent** и **Message Content Intent**, нажмите *Reset Token*.
3. Скопируйте `.env.example` в `.env` и вставьте токен в `DISCORD_TOKEN=`.
   (`OWNER_ID` уже стоит `1012623951719051284` — этот человек может всё на любом сервере.)
4. `python main.py`
5. Ссылка для добавления бота (подставьте Application ID):
   `https://discord.com/oauth2/authorize?client_id=ВАШ_ID&scope=bot+applications.commands&permissions=268553216`
   (права: просмотр каналов, сообщения, встраиваемые ссылки, файлы, история, управление ролями).

Совет: чтобы слэш-команды появились мгновенно при тестах, укажите `DEV_GUILD_ID`.
Для красивой карточки положите в папку `fonts/` файлы `font.ttf` и `font-bold.ttf` (например Montserrat, с кириллицей) —
иначе возьмётся системный шрифт.

## Как это работает

**При добавлении на сервер** бот пишет приветствие с мастером настройки (также `m!setup`):

| Шаг | Что настраивается |
|---|---|
| 1. Режим | 🛡️ *Модератор* — бот просит роль с правами администратора, пока не получит — дальше не пустит; может кикать/банить при ЧС и выдавать роли. 👁️ *Смотрящий* — только учёт, сразу к настройке |
| 2. Роль главы | выбор из списка |
| 3–4. Название сервера и банды | форма |
| 5. Обмен информацией | разрешить/запретить показ выговоров, ЧС и должностей игроков этого сервера на других серверах |
| 6. Степени ↔ роли | роль → степень 1, 2 или 3 (1 — высшая) |
| 7. Возможности степеней | выдача/снятие предупреждений, выговоров, ЧС, редактирование карточек |
| 8. Каналы | канал выговоров/предупреждений и канал ЧС |

Степень 1 наследует возможности степеней 2 и 3, степень 2 — степени 3. Степень 1 выдаёт роли степеней 2–3, степень 2 — роли степени 3.
Шаги 2–8 могут выполнять глава и владелец бота (плюс владелец сервера; пока глава не назначен — администраторы).
`m!settings` — панель со всем списком, любой шаг можно открыть повторно.

### Команды

**Настройка (префикс `m!`)**: `m!setup`, `m!settings`, `m!caps`,
`m!set head|name|gang|share|mode|action|degree|caps|reprimands|blacklist …` (подробности — `m!set`).

**Наказания** — слэш-команды открывают форму (модальное окно):
`/выговор [тип]`, `/снять-выговор [тип]`, `/чс`, `/снять-чс`.
То же через префикс: `m!warn <кому> <причина>`, `m!reprimand …`, `m!bl <кому> <причина> | <условие снятия>`,
`m!unwarn`, `m!unreprimand`, `m!unbl`. Без аргументов бот покажет кнопку **«Открыть форму»**.
«Кому» принимает: @упоминание, ID, ник Discord, игровой ник или Steam ID (карточка создаётся автоматически).

* 3 предупреждения → автоматически 1 выговор.
* 3 выговора → все действующие наказания аннулируются, в канал выговоров уходит сообщение с пингом главы.
* Если у игрока несколько действующих выговоров — при снятии бот предложит выбрать, какой снять.

**Карточки**: `/моя-карточка`, `/карточка игрок` (с автодополнением), `m!card [игрок]`, `/карточка-редактировать`,
`/история`. Под карточкой кнопки: ✏️ редактировать, 🔄 обновить, 📜 история, ссылки на Steam/UnionTeam.

* Свою карточку и её историю видите полностью. Чужая карточка для обычного участника — ник, Steam ID, ссылки;
  выговоры/ЧС/должность видит персонал (глава и любая степень).
* Поля может менять сам игрок, глава, владелец бота и степени с возможностью «Редактирование карточек».
* **Всё, что выдано/задано на одном сервере, меняется только на нём** (наказания, а также поля карточки, закреплённые за сервером).
* Кольцо вокруг аватара: зелёное — чисто, жёлтое — предупреждения, оранжевое — выговоры, красное — ЧС.

**Таблицы и роли**: `/таблица-ролей` (`m!roles`), `/таблица-участников` (`m!members`) — листаются кнопками,
порядок как в Discord; обновление — кнопка 🔄, `/обновить-таблицы` или `m!refresh`.
`/роль-выдать`, `/роль-снять` (`m!giverole`, `m!takerole`) — по правилам степеней.

**Владелец бота**: `m!sync`, `m!guilds`, `m!leave <id>`; обходит все проверки прав и видит информацию даже с серверов без обмена.

## Структура

```
main.py        запуск       config.py   настройки/константы    db.py     SQLite
perms.py       права        util.py     поиск игрока, помощники cardimg.py картинка карточки
cogs/setup.py  мастер и m!set    cogs/punish.py  наказания    cogs/cards.py  карточки
cogs/roles.py  таблицы и роли    cogs/misc.py    справка, ошибки, команды владельца
```
